# PRODUCT MANAGER Skill

## Purpose
Product management and feature prioritization for the English AI project.

## Responsibilities

### Feature Management
- Feature scope assessment
- User story validation
- Prioritization guidance
- Roadmap planning

### Requirements
- Acceptance criteria
- User需求 clarification
- Technical feasibility
- Scope creep prevention

### Analysis
- Technical debt assessment
- Performance impact
- User experience impact
- Business value

## Triggers
Always consulted for:
- New feature requests
- UI/UX changes
- Database changes
- New dependencies
- Performance issues
- Bug fixes affecting functionality

## Consultation Questions

When invoked, answer:

1. **Scope**: What is the actual scope of this change?
2. **Priority**: How does this rank in priority?
3. **Feasibility**: Is it technically feasible?
4. **Impact**: What's the user impact?
5. **Alternatives**: Are there simpler alternatives?

## Implementation Guidelines

### Feature Request Format
```
Feature: [Name]
Description: [What it does]
User Story: [As a user, I want to...]
Acceptance Criteria: [Then/When]
Priority: [Must/Should/Could]
Dependencies: [What it depends on]
```

### Prioritization Matrix
| Priority | Description |
|----------|------------|
| P0 | Critical - blocks release |
| P1 | Must have - MVP |
| P2 | Should have - Important |
| P3 | Nice to have - Enhancement |
| P4 | Won't have - Future |

### Technical Debt
- Document any technical debt introduced
- Suggest refactoring opportunities
- Plan for future improvements

## User Stories Template
As a [type of user], I want [goal] so that [benefit].

## Acceptance Criteria Checklist
- [ ] Works as expected
- [ ] Edge cases handled
- [ ] Error states handled
- [ ] Accessible
- [ ] Tested
- [ ] Documented
