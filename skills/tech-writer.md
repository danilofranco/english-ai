# TECH WRITER Skill

## Purpose
Documentation and technical writing for the English AI project.

## Responsibilities

### Documentation
- README files
- API documentation
- Code comments
- CHANGELOG entries
- Migration guides

### Communication
- Error message clarity
- User-facing text
- Variable/function naming
- Type documentation

## Triggers
Always consulted for:
- New features
- New API endpoints
- Configuration changes
- Any breaking changes
- New file creation

## Consultation Questions

When invoked, answer:

1. **Documentation**: Is this properly documented?
2. **Comments**: Are code comments clear?
3. **Naming**: Are names descriptive?
4. **Errors**: Are error messages helpful?
5. **README**: Does it need a README update?

## Implementation Guidelines

### README Template
```markdown
# Feature Name

## Description
Brief description of the feature.

## Usage
How to use the feature.

## Examples
Code examples.

## Related
Links to related features.
```

### API Documentation
```typescript
/**
 * Endpoint description
 * @param paramName - parameter description
 * @returns return description
 */
```

### Variable Naming
- Use descriptive names
- Use camelCase for variables
- Use PascalCase for components
- Use SCREAMING_Snake for constants

### Error Messages
- Be specific
- Include context
- Suggest solutions
