# UX/UI EXPERT Skill

## Purpose
User experience and interface design for the English AI project.

## Responsibilities

### UI Design
- Component design review
- Visual consistency
- Color and typography
- Iconography
- Responsive design

### User Experience
- User flow optimization
- Navigation patterns
- Loading states
- Error handling UI
- Accessibility (WCAG)

### Interaction Design
- Form interactions
- Button states
- Hover/focus states
- Animations
- Transitions

## Triggers
Always consulted for:
- Page/Route creation or modification
- Component creation
- CSS/Tailwind changes
- Form implementations
- Navigation changes
- Any visual changes

## Consultation Questions

When invoked, answer:

1. **Accessibility**: Does this meet WCAG guidelines?
2. **Responsive**: Is it mobile-first?
3. **Consistency**: Does it match the design system?
4. **UX**: Is the user flow intuitive?
5. **States**: Are all states handled (hover, focus, disabled)?
6. **Feedback**: Is user feedback clear?

## Implementation Guidelines

### Design System
- Primary color: Match brand guidelines
- Use established components
- Follow spacing system (4px base)
- Use typography scale

### Accessibility
- Alt text for images
- Aria labels where needed
- Keyboard navigation
- Color contrast ratios
- Focus indicators

### Responsive Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## Components to Use
- Buttons with proper states
- Input fields with labels
- Cards for content
- Modals for confirmations
- Toasts for feedback
- Loading spinners
